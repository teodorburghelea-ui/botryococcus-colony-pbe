# Microscopy-constrained prospective model-selection test

This is an event-conditioned in-silico protocol design, not a fit to Uno or Suzuki microscopy. No biological rate, event hazard, kernel parameter, shell-loss fraction, or reset time was estimated.

## Structural candidate set

Twelve closures combine three unresolved biological kernels, two shell alternatives, and two daughter reset rules. All use the same 720 synthetic tracked events and known two-pulse schedule, so candidate differences are structural mappings rather than rate effects.

## Declared prospective discrimination criterion

A pair is called distinguishable only when its standardized signal is at least 3.0 under the declared measurement resolution. The result is a protocol-adequacy statement, not an empirical model ranking.

- Time-resolved distributions: 32/66 candidate pairs.
- Paired lineage only: 52/66 candidate pairs.
- Shell label only: 36/66 candidate pairs.
- State trajectory only: 36/66 candidate pairs.
- All planned readouts: 66/66 candidate pairs.

Time-resolved size distributions cannot see a reset rule that leaves the immediate material map unchanged. Paired mother--descendant sizes resolve kernel topology, a shell label resolves structural loss, and a time-resolved daughter marker resolves reset. Existing microscopy supplies none of these statistical event datasets, so it does not select one closure.
