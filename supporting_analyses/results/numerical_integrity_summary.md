# Numerical-integrity results

All values use fixed, deliberately uncalibrated numerical test parameters.
The largest independent M1-ledger residual across the eight Eq. (3) tests is 1.232e-15; the smallest cell population is 2.746e-63.
For the diameter transformation, refinement from Nx=32 to Nx=256 reduces the CDF L∞ error from 2.254e-03 to 3.526e-05 and the volume-weighted-diameter error from 2.435e-10 to 4.627e-12.
For the biological daughter kernel, the CDF L∞ error relative to Nx=512 falls from 1.595e-01 (Nx=32) to 2.302e-02 (Nx=256).
For the hydrodynamic daughter kernel, the CDF L∞ error relative to Nx=512 falls from 1.486e-01 (Nx=32) to 2.193e-02 (Nx=256).

The test is intentionally a numerical-verification artifact, not a calibrated biological prediction.
